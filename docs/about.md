hyprmoncfg is an open source Hyprland monitor configuration tool. It ships a terminal layout editor for arranging displays, a profile system for saving hardware-aware monitor layouts, and a daemon that can apply the right profile when monitors are plugged in or a laptop lid changes state.

The canonical source repository is [crmne/hyprmoncfg](https://github.com/crmne/hyprmoncfg). Stable and development Arch Linux packages are published as [hyprmoncfg](https://aur.archlinux.org/packages/hyprmoncfg) and [hyprmoncfg-git](https://aur.archlinux.org/packages/hyprmoncfg-git) in the AUR.

hyprmoncfg is created by [Carmine Paolino](https://paolino.me/).
